# Content Factory

Plataforma inteligente de gestión, automatización y producción de contenidos para marketing.

## ¿Qué hace?

- **Bosque**: catálogo de fuentes RSS + ingreso manual por link o texto.
- **Galpón**: recolección inteligente con clasificación, deduplicación y priorización.
- **Fábrica**: producción de piezas para Instagram (Post, Historia, Carrusel) con editor visual, plantillas, logos y exportación.
- **Calidad**: control e inventario de piezas terminadas.
